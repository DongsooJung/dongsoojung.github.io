# Google Calendar 공개 일정 자동 동기화

`jds068888@gmail.com`의 기본 캘린더에서 제목이 `[공개]`로 시작하는 일정만 별도 캘린더 **정동수 주요 일정**으로 복사합니다.

## 공개 규칙

- 공개: `[공개] 대치동 KOI 특강`
- 비공개: `병원 방문`, `개인 미팅` 등 `[공개]`가 없는 모든 일정
- 공개 캘린더에는 제목과 시간만 복사
- 참석자, 이메일, 원본 설명, Google Meet 링크, 개인 메모는 복사하지 않음
- 원본 일정 수정·삭제 시 15분 이내 공개 캘린더에도 반영
- 동기화 범위: 과거 30일 ~ 향후 365일

## 최초 설치

1. PC에서 `jds068888@gmail.com`으로 [Google Apps Script](https://script.google.com/)에 로그인합니다.
2. **새 프로젝트**를 만들고 이 폴더의 `Code.gs` 내용을 붙여넣습니다.
3. 프로젝트 설정에서 `appsscript.json` 표시를 켜고 이 폴더의 manifest 내용으로 교체합니다.
4. 함수 목록에서 `setupPublicCalendarSync`를 선택해 한 번 실행하고 권한을 승인합니다.
5. 실행 로그의 `PUBLIC_CALENDAR_ID=` 뒤 값을 복사합니다.
6. Google Calendar 설정에서 새로 생성된 **정동수 주요 일정** 캘린더를 공개로 설정합니다.
7. 홈페이지 `/schedule/`의 iframe 캘린더 ID를 이 공개 캘린더 ID로 교체합니다.

## 운영

이후 Gmail 기본 캘린더에서 공개하려는 일정 제목 앞에 `[공개]`만 붙이면 됩니다. 자동화가 복사하는 공개 캘린더에서 직접 편집하지 마세요.
