데이터 상태: 정성 검토·제안

우선순위는 기존 대시보드와의 연결성, 데이터 확보 난이도에 대한 판단입니다. 시장 규모·판매가격·수익을 실측한 결과가 아닙니다. 이 페이지는 사업 검토 보고서이며 3D 차트·지도·공간 모델의 운영 기능은 아직 구현하지 않았습니다.

3D 데이터 분석

매출·성장률·이익률처럼 세 변수의 관계와 시간에 따른 이동을 탐색합니다. 기존 기업 재무·경매 보고서와 연결할 수 있습니다.

3D 공간 모델링

건물·실내·창고의 형태와 배치를 재현합니다. 실측·도면과 운영 데이터를 확보해 공간 사용과 사업성을 함께 검토합니다.

사업 후보와 우선순위

우선순위는 착수 검토 순서입니다. 수요·계약 가능성이 확인된 사업 순위는 아닙니다.

공간 사업 손익 곡면

X 가동률 · Y 이용가격 · Z 월 영업이익. 미니창고·짐보관·안마의자 사업에 적용합니다.

월 영업이익 = 판매 가능 용량 × 가동률 × 단위가격 − 변동비 − 고정비. 단위와 판매기간을 통일하며 초기 투자 회수는 별도 계산합니다.

제품 구성과 검증 기준

  • 공통 조작: 회전·확대, 항목 선택, 연도 필터, 초기 시점 복원, 2D 전환과 원자료 표를 제공합니다.
  • 데이터 표시: 실제값·추정값·가정값을 구분하고 출처·기준일·갱신일·계산식을 함께 표시합니다. 미확보 값은 빈 값으로 둡니다.
  • 모바일: 가독성과 터치 조작을 확인하고, 3D가 가려지거나 작동하지 않아도 표·2D로 같은 정보를 확인하도록 설계합니다.
  • 고객 검증: 실제 의사결정 사례에서 고객이 비교할 대상을 찾는 시간, 분석 결과의 활용 여부와 유료 의향을 확인합니다.

실행 순서

  1. 기초 데이터 점검: 재무 보고서의 비교 기준과 공개 범위를 정리하고 공간 사업의 치수·비용·용량 가정을 수집합니다.
  2. 분석 시제품: 기업 비교 산점도와 공간 사업 손익 곡면을 먼저 검증합니다. 샘플을 사용하면 데모로 명시합니다.
  3. 공간 확장: 대상 지역·건물의 데이터 범위와 사용 조건을 확인한 뒤 3D 지도·실내 모델을 연결합니다.
  4. 판매 검증: 맞춤 보고서와 사업성 검토를 소규모로 제공한 뒤 반복 수요가 확인된 기능을 구독형으로 확장합니다.

판단: 입지·투자·공간 배치를 결정하는 데 도움이 되는 분석을 상품화합니다. 단순 시각 효과보다 비교 가능성과 데이터 신뢰도를 우선합니다.
