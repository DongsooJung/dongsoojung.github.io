# App Privacy 영양 라벨

`../play-console-answers.md` 6항과 `privacy.html`을 App Store Connect 데이터 유형으로 옮긴 표입니다. 추적(광고·데이터 브로커·제3자 광고)은 하지 않습니다.

Play 공개 페이지는 위치를 제3자 공유로 보여 줍니다. 이 표는 그 표시가 아니라 답변표를 따릅니다. 위치는 날씨 조회를 위해 Open-Meteo로만 잠시 보내지고, 운영자 서버에는 저장되지 않습니다.

| Apple 데이터 유형 | 수집 | 필수 | 목적 | 신원 연결 | 추적 | 근거 |
|---|---|---|---|---|---|---|
| 연락처 정보 › 이름 | 예 | 선택 | 앱 기능 | 예 | 아니요 | `/consult/` 상담 폼 |
| 연락처 정보 › 전화번호 | 예 | 선택 | 앱 기능 | 예 | 아니요 | `/consult/` 상담 폼 |
| 식별자 › 사용자 ID | 예 | 분석용은 필수, 간편 입력은 선택 | 앱 기능, 분석 | 간편 입력의 `social_id`만 연결 | 아니요 | 카카오·네이버 `social_id`와 무작위 방문자·세션 ID. 광고 ID는 아님. 계정은 만들지 않음 |
| 사용 데이터 › 제품 상호작용 | 예 | 필수 | 분석 | 아니요 | 아니요 | `assets/usage-analytics.js` 페이지 경로·클릭 |
| 위치 › 대략적인 위치 | 예 | 선택 | 앱 기능 | 아니요 | 아니요 | `/strategy/weather-calendar/` → Open-Meteo. 저장하지 않음 |

이메일, 결제, 사진, 연락처 주소록, 건강, 메시지는 수집하지 않습니다. 사진 라이브러리 권한은 수학 데모가 기기에 저장하지 않는 미리보기라면 선언하지 않습니다. 구현이 사진을 업로드하기 시작하면 이 표와 `privacy.html`을 먼저 고칩니다.

삭제 요청은 `support@stargateedu.co.kr`입니다.

## 연령 등급 설문

| 질문 | 답 |
|---|---|
| 폭력, 성적 콘텐츠, 욕설, 약물, 도박 | 없음 |
| 사용자 간 소통, 사용자 제작 콘텐츠 공개 | 없음 |
| 다른 사용자에게 위치 공유 | 없음 |
| 디지털 상품 구매 | 없음 |
| 아동을 대상으로 함 | 아니요 |
| 제한 없는 웹 접근 | 예. 포털 전체를 열면 외부 링크도 따라갈 수 있음 |

제한 없는 웹 접근이 예이면 Apple 산출 등급은 17+입니다. 답변표 5항의 대상 연령 18세 이상과 같이, 아동용 카테고리에는 넣지 않습니다.
