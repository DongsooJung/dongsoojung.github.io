## 앱 이름 (30자 이내)
STARGATE 관리자

## 간단한 설명 (80자 이내)
스타게이트의 연구·전략 프로젝트를 한곳에서 찾고, 할 일을 기기에 기록하는 관리 워크스페이스

## 자세한 설명 (4,000자 이내)
STARGATE 관리자는 스타게이트(주식회사 별의문)가 공개한 연구·전략 프로젝트를 한 화면에서 찾아보고, 프로젝트별 할 일을 기록하는 관리용 워크스페이스입니다. 회원가입이나 로그인 없이 바로 쓸 수 있습니다.

■ 프로젝트 찾기
· 연구·전략 프로젝트 목록을 주제별로 탐색
· 전체 프로젝트 빠른 검색
· 프로젝트를 누르면 해당 공개 페이지로 이동

■ 할 일 기록
· 프로젝트별 작업 추가, 검색, 정렬
· 오늘의 현황 화면에서 진행 상태 확인

■ 기록 보관 방식
· 기록은 이 기기에만 저장되며 서버로 전송하지 않습니다
· 설정 화면의 JSON 백업과 복원으로 기록을 파일로 보관하고 되살릴 수 있습니다
· 기기를 바꾸거나 앱 데이터를 지우면 기록이 사라지므로 JSON 백업으로 보관해 주세요

■ 편의 기능
· 라이트·다크 화면 전환
· 인터넷이 끊겨도 마지막으로 불러온 화면 열람
