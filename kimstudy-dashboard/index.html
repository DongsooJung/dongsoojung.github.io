Setup

수집기 설치

김과외 목록 API는 로그인 세션이 필요한 동일 출처 리소스이므로 수집은 kimstudy.com 탭 안에서 실행됩니다. 아래 스크립트를 콘솔에 한 번 붙여넣으면 우측 하단에 대시보드 버튼이 생기고, [수집 시작]을 누를 때마다 집계값이 이 페이지로 자동 반영됩니다.

실행 순서

Chrome 기준
  1. 김과외 학생 찾기 페이지에서 원하는 과목·지역 필터를 적용합니다.
  2. 로컬에 보관된 김과외_학생찾기_수집기.js 파일을 메모장으로 열어 전체 복사합니다. (또는 김과외_학생찾기_대시보드.html 의 [스크립트 복사] 버튼 이용)
  3. 김과외 탭에서 F12 → Console에 붙여넣고 Enter.
  4. 우측 하단 [KS 대시보드] → 범위 선택 → [수집 시작].
  5. 「자동 적재」가 켜져 있으면 수집 직후 이 페이지에 반영됩니다. 토큰이 비어 있다면 [토큰] 버튼으로 한 번만 등록하십시오.
수집기를 공개 배포하지 않는 이유 · 수집기에는 서버 적재 토큰이 포함됩니다. 이 페이지에 함께 올리면 누구나 임의 데이터를 적재할 수 있으므로, 수집기 파일은 운영자 PC에만 보관하고 이 대시보드는 읽기 전용으로 운영합니다.

수집 파이프라인

데이터가 흐르는 경로
  1. 브라우저 — 본인 세션으로 목록 API 순회 (페이지 크기 자동 판별, 0.3초 지연)
  2. 집계 — 지역·과목·학년·계열·경쟁강도·제안구간·끌올일 10개 차원으로 요약
  3. 전송 — Edge Function이 토큰 검증 후 집계값만 적재 (허용 차원 화이트리스트 검증으로 개인정보 유입 차단)
  4. 조회 — 이 대시보드가 익명 읽기 전용 권한으로 조회
