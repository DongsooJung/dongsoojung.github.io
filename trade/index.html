무역 월별 대시보드 국가별 수출입실적

관세청 국가별 수출입실적(GW) Open API를 월 단위로 집계한 인터랙티브 무역통계입니다. 수출은 최종목적국·FOB 신고금액, 수입은 원산국·CIF 과세가격 기준이며, 매월 15일경 신고 정정·취하를 반영해 전월 자료가 현행화됩니다. GitHub Actions가 매월 자동 갱신합니다.

데이터 기준 — 커버리지 — 단위 미화 달러 · 수출 FOB / 수입 CIF —
관세청 API로 갱신된 최신 파일을 다시 불러옵니다.
지금 보이는 값은 시드(예시) 데이터입니다. 공표 통계 기반 근사치와 추세 연장 예시치로 구성했으며, 저장소에 CUSTOMS_API_KEY(공공데이터포털 인증키)를 등록하면 다음 자동 실행 때 관세청 API 실측치로 전량 대체됩니다. 설정 방법은 하단 안내 참고.

데이터 출처 및 기준 — 공공데이터포털 관세청_국가별 수출입실적(GW) (apis.data.go.kr/1220000/nationtrade/getNationtradeList)를 월 단위로 호출해 집계합니다. 국가분류는 무역통계부호의 ISO 국가코드 기준이며, 수출은 최종목적국 · FOB 신고미화금액, 수입은 원산국 · CIF 과세가격미화금액입니다. 관세청은 매월 15일경 신고 정정·취하 등 변경내역을 반영해 전월까지 자료를 현행화하므로, 자동 갱신은 매월 16일 실행되고 최근 3개월은 항상 재수집합니다. 국가별 내역은 수출액 기준 상위 40개국을 저장합니다.

API 키 설정 — 공공데이터포털에서 활용신청 후 발급받은 Decoding 인증키를 저장소 Settings → Secrets and variables → Actions에 CUSTOMS_API_KEY로 등록하면 GitHub Actions(update-trade-data.yml)가 매월 data.json을 갱신합니다. 시크릿 없이 1회 실행하려면 워크플로 수동 실행(workflow_dispatch)의 api_key 입력을 사용하세요. 자세한 내용은 README 참고.
