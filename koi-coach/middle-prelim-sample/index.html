2026 KOI 1차 중등부 실기에서 요구되는 ‘큰 입력을 정렬하고 구간의 원소 수를 빠르게 세는’ 사고를 연습하기 위한 교육용 재구성 샘플입니다.

표기 안내 · 현재 공식 명칭은 KOI ‘1차 대회’이며 초·중등부에는 전국부문과 지역부문 시상이 있습니다. 이 페이지의 ‘지역예선형’은 학습 편의를 위한 표현이며 실제 기출 원문을 복제한 것이 아닙니다.

1. 문제

수직선 위에 N명의 학생이 있고, i번 학생의 위치는 Xᵢ, 소속 스터디 그룹은 Sᵢ이다. i번 학생과 j번 학생(i≠j)이 파트너가 되는 조건은 다음 중 하나이다.

  • 같은 그룹이면 |Xᵢ-Xⱼ| ≤ A
  • 다른 그룹이면 |Xᵢ-Xⱼ| ≤ B

N이 최대 200,000일 때 모든 학생에 대해 파트너 수를 구하여라.

예시 입력

7 3 5 2 1 5 2 7 1 11 3 14 1 16 2 20 3

예시 출력

1 2 2 3 2 3 1

2. 힌트

N²개의 학생 쌍을 모두 확인하면 최대 약 4×10¹⁰번 비교가 필요합니다. 각 학생마다 “특정 구간 안에 위치한 학생 수”만 빠르게 셀 수 있다면 문제를 줄일 수 있습니다.

rangeCount(sorted, L, R) = upper_bound(R) - lower_bound(L)

3. 설계

1
전체 위치 배열을 정렬
모든 X를 정렬한 배열 all에 저장합니다.
2
그룹별 위치 배열도 정렬
group[S]에는 같은 그룹 학생의 위치만 모읍니다.
3
B 범위의 전체 학생 수 계산
[Xᵢ-B, Xᵢ+B] 안의 전체 학생 수를 이분 탐색으로 구합니다.
4
같은 그룹을 보정
B 범위의 같은 그룹을 빼고, A 범위의 같은 그룹을 다시 더합니다.
answerᵢ = allWithin(B) - sameGroupWithin(B) + sameGroupWithin(A) - 1

마지막 −1은 sameGroupWithin(A)에 자기 자신이 포함되기 때문입니다.

시간 O(N log N)메모리 O(N)

4. C++20 구현

#include <bits/stdc++.h> using namespace std; using ll = long long; int countRange(const vector<ll>& v, ll L, ll R){ return upper_bound(v.begin(), v.end(), R) - lower_bound(v.begin(), v.end(), L); } int main(){ ios::sync_with_stdio(false); cin.tie(nullptr); int N; ll A, B; cin >> N >> A >> B; vector<ll> X(N), all; vector<int> S(N); vector<vector<ll>> group(N + 1); for(int i=0;i<N;i++){ cin >> X[i] >> S[i]; all.push_back(X[i]); group[S[i]].push_back(X[i]); } sort(all.begin(), all.end()); for(auto& g : group) sort(g.begin(), g.end()); for(int i=0;i<N;i++){ int allB = countRange(all, X[i]-B, X[i]+B); int sameB = countRange(group[S[i]], X[i]-B, X[i]+B); int sameA = countRange(group[S[i]], X[i]-A, X[i]+A); int ans = allB - sameB + sameA - 1; cout << ans << (i+1==N?'\n':' '); } }

위 예시 학생 7명은 그대로 두고 A와 B를 움직여 파트너 수가 어떻게 바뀌는지 확인해 보세요.

6. KOI 연결 포인트

  • 브루트포스에서 시간복잡도 병목을 먼저 찾는다.
  • 정렬된 배열에서 구간 개수를 lower_bound / upper_bound로 센다.
  • “전체 − 제외 + 다시 포함” 형태로 조건을 분리한다.
  • 부분점수 풀이 O(N²)에서 만점 풀이 O(N log N)으로 개선하는 과정을 설명할 수 있어야 한다.
