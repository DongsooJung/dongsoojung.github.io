도서관 자리 친구
이웃 탐색 문제

2026 KOI 1차 초등부 1번 ‘이웃’에서 볼 수 있는 핵심 사고인 가까운 위치의 대상을 조건에 따라 세기를 연습하기 위한 교육용 재구성 샘플입니다.

표기 안내 · 2026 KOI 공식 초등부 2교시 문제는 ‘이웃’, ‘가위바위보’, ‘수열 정렬하기’ 3문항이었습니다. 이 페이지는 실제 지문·예제·해설을 복제하지 않고 동일 연도 난이도와 학습 포인트를 참고해 새로 만든 문제입니다.

1. 문제

도서관에 1번부터 N번까지 일렬로 좌석이 있고, 각 좌석에는 학생 한 명이 앉아 있다. 학생은 1번 또는 2번 독서모임에 속한다.

  • 같은 모임 학생끼리는 좌석 번호 차이가 A 이하이면 친구다.
  • 다른 모임 학생끼리는 좌석 번호 차이가 B 이하이면 친구다.
  • 자기 자신은 친구 수에 포함하지 않는다.

각 학생마다 친구가 몇 명인지 차례대로 출력하라.

2 ≤ N ≤ 3000 · 1 ≤ A,B ≤ N-1 · Cᵢ ∈ {1,2}

2. 예시

입력
8 2 1 1 2 1 1 2 2 1 2
출력
2 2 3 2 2 3 2 2

3. 힌트 → 풀이 설계

1
먼저 그대로 검사한다.
학생 i를 하나 정하고 다른 학생 j를 모두 보면서 같은 모임인지, 다른 모임인지에 따라 A 또는 B와 거리를 비교한다.
2
N≤3000이면 O(N²)도 충분하다.
최대 약 900만 번의 비교이므로 초등부 1번 수준에서는 가장 안전하고 구현이 쉬운 정답 전략이다.
3
개선 아이디어: prefix count.
1번 모임과 2번 모임의 누적 개수를 따로 저장하면 [L,R] 구간에 각 모임 학생이 몇 명 있는지 O(1)에 구할 수 있다.
4
한 학생의 답을 두 구간 합으로 만든다.
같은 모임은 [i-A,i+A], 다른 모임은 [i-B,i+B]에서 세고, 같은 모임 계산에서 자기 자신 1명을 뺀다.

4. 난이도별 접근

기본: O(N²)개선: O(N)메모리: O(N)

대회에서는 먼저 확실한 O(N²) 정답을 완성한 뒤, 시간이 남으면 누적합 풀이로 확장하는 식의 전략도 좋습니다.

5. C++20 — 가장 직관적인 정답

#include <bits/stdc++.h> using namespace std; int main() { ios::sync_with_stdio(false); cin.tie(nullptr); int N, A, B; cin >> N >> A >> B; vector<int> C(N); for (int &x : C) cin >> x; for (int i = 0; i < N; ++i) { int cnt = 0; for (int j = 0; j < N; ++j) { if (i == j) continue; int d = abs(i - j); if (C[i] == C[j]) { if (d <= A) ++cnt; } else { if (d <= B) ++cnt; } } cout << cnt << (i + 1 == N ? '\n' : ' '); } return 0; }

6. C++20 — prefix count 개선

#include <bits/stdc++.h> using namespace std; int main() { ios::sync_with_stdio(false); cin.tie(nullptr); int N, A, B; cin >> N >> A >> B; vector<int> C(N + 1); vector<array<int, 3>> ps(N + 1); for (int i = 1; i <= N; ++i) { cin >> C[i]; ps[i] = ps[i - 1]; ps[i][C[i]]++; } auto countGroup = [&](int g, int l, int r) { l = max(l, 1); r = min(r, N); if (l > r) return 0; return ps[r][g] - ps[l - 1][g]; }; for (int i = 1; i <= N; ++i) { int same = countGroup(C[i], i - A, i + A) - 1; int otherGroup = 3 - C[i]; int other = countGroup(otherGroup, i - B, i + B); cout << same + other << (i == N ? '\n' : ' '); } }

7. 인터랙티브 검증

고정 학생 배열 1 2 1 1 2 2 1 2에서 A와 B를 바꿔 보세요.

8. 이 문제에서 가져갈 것

  • 제약 조건 N을 보고 완전탐색이 가능한지 먼저 판단한다.
  • 조건이 두 종류면 분기문을 정확히 나눈다.
  • ‘구간 안의 개수’를 여러 번 묻는다면 누적합을 떠올린다.
  • 정답 코드는 복잡한 것보다 검증하기 쉬운 것이 우선이다.
