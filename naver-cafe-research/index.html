Collection Method

차단에 강한 3단계 수집

01

공개 API 우선

화면 OCR보다 정확한 공개 인기글 응답을 먼저 사용합니다.

02

읽기 브리지

정적 사이트의 브라우저 제한은 공개 읽기 브리지로 처리합니다.

03

OCR 보조

구조화 응답이 막힌 화면은 사용자가 볼 수 있는 범위에서만 OCR로 확인합니다.

04

시간별 캐시

실시간 요청 실패에도 마지막 성공 데이터가 유지됩니다.

실시간 버튼은 Jina AI Reader를 읽기 전용 교차 출처 브리지로 사용할 수 있습니다. 공개 네이버 API 주소만 전달하며 계정·쿠키·개인정보는 전송하지 않습니다.
