# Security Policy

## Supported scope

Security reports are welcome for the currently deployed source in this repository, including:

- public portal pages and PWA assets;
- Vercel API routes and server-side proxies;
- GitHub Actions workflows and deployment configuration; and
- accidental exposure of credentials or sensitive data in the current tree.

Third-party services and assets that are not controlled by this repository are outside the scope, unless the report demonstrates a vulnerability in this repository's integration with them.

## Reporting a vulnerability

Please **do not open a public issue** for a suspected security vulnerability or possible credential exposure.

Send a concise report to **ceo@stargateedu.co.kr** with:

1. a description of the issue and the affected URL, file, or workflow;
2. safe reproduction steps or a proof of concept;
3. the potential impact; and
4. any suggested mitigation.

Do not include live API keys, customer data, or credentials in the report. If a secret may be exposed, identify its location and type without reproducing its value.

## Good-faith testing

Good-faith research is welcome when it avoids privacy violations, service disruption, social engineering, and destructive or high-volume testing. Do not access, modify, or delete data that is not yours.
