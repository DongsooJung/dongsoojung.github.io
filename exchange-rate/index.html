통화별 월평균 매매기준율 · 괄호는 선택 통화 전월비 · 기준금리/물가는 우측 열
데이터 출처 및 갱신 — 한국수출입은행 환율정보 Open API(현재환율, data=AP01)의 일일 매매기준율(deal_bas_r)을 영업일마다 수집해 월평균·월최저·월최고로 집계합니다. GitHub Actions가 매월 data.json을 갱신하며, 확정된 과거 월은 그대로 두고 최근 2개월만 재집계합니다. 현재 표시 중인 시드 데이터는 근사 월평균(approx)으로 USD/KRW·교차환율 근사치에서 산출했으며, EXIM_API_KEY 등록 시 API 정밀치로 대체됩니다. 엔(JPY)은 100엔당 고시 기준입니다.

금리 · 물가 — 한국은행 ECOS 경제통계시스템 API에서 한국은행 기준금리(통계표 722Y001)와 소비자물가지수(901Y009, 2020=100)를 월별로 수집하며, 물가상승률은 소비자물가지수의 전년동월비(YoY)입니다. BOK_API_KEY 등록 시 근사 시드가 ECOS 정밀치로 대체됩니다. 설정 방법은 README 참고.
