PARTNERSHIP RULES제휴·광고는 이렇게 다룹니다

  • 회원 혜택이 먼저입니다. 광고비보다 회원 전용 가격, 무료 체험, 추가 서비스 같은 구체적인 혜택을 먼저 협의합니다.
  • 모든 제휴는 표시합니다. 제휴 사실, 업체명, 혜택 조건과 기간을 게시물에 밝힙니다.
  • 검증되지 않으면 올리지 않습니다. 교육 품질·개인정보 처리·환불 조건을 확인하고, 과장 광고나 회원 정보 제공 요구는 거절합니다.
  • 쓰임을 공개합니다. 광고비를 받게 되면 회원 혜택과 카페 운영에 어떻게 쓰는지 공개합니다.
  • 회원에게 직접 연락하지 않습니다. 협력 업체의 개별 연락과 반복 홍보 게시는 허용하지 않습니다.

ROADMAP첫 3개월

  1. 준비카페 소개·가입 질문·등업 기준·제휴 원칙을 정하고 기본 자료를 게시합니다.
  2. 초기 운영주 2~3회 교육 정보와 질문형 게시물을 올리고 운영자가 빠르게 답합니다.
  3. 참여 확대무료 온라인 특강과 진로·학습 Q&A를 열고 회원 후기와 자료를 모읍니다.
  4. 제휴 시험회원 의견을 먼저 듣고 소규모 혜택 제휴를 진행한 뒤 결과를 공개 점검합니다.
