KMO 1차 대비 모의고사

KMO 1차 단답형 형식(정답이 0 이상 999 이하의 정수)에 맞춘 스타게이트 자체 문항입니다. 제출하면 정오표와 영역별 정답률이 바로 나옵니다.

안내
  • 모든 문항은 스타게이트가 직접 만든 연습 문항이며, KMO 기출 원문이나 공식 출제 경향 자료가 아닙니다.
  • 응시 시간과 배점(문항당 5점)은 이 모의고사의 자체 설정입니다.
  • 채점은 브라우저 안에서 이루어지고, 답안은 이 기기에만 저장됩니다. 순위는 집계하지 않습니다.

응시 정보

-문항
-제한 시간(분)
-만점
-권장 응시 기간
문항을 불러오는 중입니다.

문제

답은 0 이상 999 이하의 정수로 입력합니다. 입력한 답은 자동 저장됩니다.
