# 금융위원회 기업재무 대시보드

금융위원회 기업 재무정보(요약재무제표) API를 **100건씩** 조회하고 Chart.js로 시각화하는 연구 대시보드입니다.

- 페이지: `/fsc-financial/`
- API: `GetFinaStatInfoService_V2` / `getSummFinaStat_V2`
- 키: 공개 소스에 인증키 없음. 본인의 발급 키가 있을 때 공식 API 조회
- 저장본: `data.json` (2023년 1페이지 100건, 수집일 2026-07-26). 이번 원표 수치 대조는 미완료. KRW 99건·CNY 1건의 원문 통화를 보존하며 원화 금액 KPI와 차트는 KRW만 사용

## 로컬 확인

정적 서버로 `fsc-financial/`을 열면 사용자 키가 없는 경우 과거 저장본을 표시합니다. 사업연도·기준일(basDt)·수집일(fetchedAt)을 구분하며, 연도 선택을 바꾸어도 CSV 파일명은 실제 표시 데이터의 사업연도를 사용합니다.
