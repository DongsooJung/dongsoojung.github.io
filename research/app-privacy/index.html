01. 적용 범위

주식회사 별의문(이하 “회사”)이 제공할 예정인 스타게이트 에듀 Android 앱(kr.co.stargateedu.app)의 개인정보처리방침 초안입니다.

본 초안은 회원가입이나 로그인 없이 교육 자료를 열람하는 정보 제공형 앱을 전제로 합니다. 로그인 기반 학습관리, 결제, 채팅, 광고 또는 분석 기능을 추가하는 경우 실제 처리 방식에 맞춰 내용을 수정해야 합니다.

연구 대시보드는 이 문서를 보관·열람하는 장소입니다. 이 초안은 stargateedu.co.kr의 현재 홈페이지·연구 대시보드 전체에 적용되는 기존 개인정보처리방침을 대체하지 않습니다.

02. 처리 항목과 목적

구분항목 및 목적적용 조건
회원 정보이름, 로그인 ID, 비밀번호, 전화번호 등을 입력받는 회원 기능을 두지 않는 구성정보 제공형 앱 전제. 최종 구현 확인 필요
기기 내 저장화면·자료의 임시 캐시. 즐겨찾기·학습기록을 도입한다면 기기 내 저장과 서버 전송 여부를 구분하여 고지실제 저장 기능 확정 후 적용. 미구현 기능을 제공한다고 의미하지 않음
웹 접속 정보IP 주소, 접속 시각, 요청 주소, 브라우저 정보 등. 화면 전달, 서비스 안정성 및 보안 운영 목적호스팅 사업자가 처리할 수 있음. 실제 항목·접근 권한·보유기간 확인 필요
이메일 문의이용자가 보내는 이메일 주소 및 문의 내용. 문의 확인·답변 목적이용자가 자발적으로 이메일 문의를 보낸 경우

분석·광고 SDK를 사용하지 않는다는 사실만으로 모든 개인정보 처리가 없다고 판단하지 않습니다. 웹사이트의 접속기록과 제3자 서비스를 포함해 실제 처리를 확인합니다. 민감정보, 주민등록번호, 결제정보 등 문의 처리에 불필요한 정보는 보내지 않도록 안내할 예정입니다.

03. 보유기간과 파기

  • 기기 내 데이터: 해당 기능을 도입하는 경우 저장 위치와 보유 조건을 명시합니다. 브라우저의 사이트 데이터 삭제로 캐시 등이 지워질 수 있으며, Android 앱 삭제만으로 브라우저 데이터가 항상 삭제되는 것은 아닙니다.
  • 접속기록: 실제 호스팅 사업자의 정책 및 운영 설정을 확인하여 구체적인 보유기간과 삭제 절차를 기재합니다.
  • 문의기록: 문의 처리에 필요한 범위로 보관하며, 구체적인 보유기간은 운영자가 확정합니다. 별도 법정 보존의무가 적용된다면 그 항목·근거·기간을 구분하여 고지합니다.

보유 목적이나 기간이 종료된 개인정보는 복구하기 어려운 방법으로 삭제하는 것을 운영 원칙으로 합니다. 실제 삭제 권한과 사업자별 처리 절차는 출시 전에 확인합니다.

확정 전: 접속기록 및 이메일 문의기록의 구체적인 보유기간·삭제 방법. 임의로 “즉시 삭제” 또는 특정 개월 수를 기재하지 않았습니다.

04. 제3자 제공·처리위탁·국외 처리

현재 공개 홈페이지 응답에서 GitHub Pages 호스팅을 확인했습니다(2026-09-01). 앱도 같은 호스팅을 사용할지는 최종 구성에 따라 확인해야 합니다. 사업자의 개인정보 처리 내용은 GitHub 개인정보처리방침에서 확인할 수 있습니다.

개인정보의 판매 또는 광고 목적 공유는 본 초안의 기능 전제에 포함하지 않습니다. 다만 웹 호스팅·이메일 등 외부 서비스의 처리를 일괄적으로 “제공·위탁 없음”으로 단정하지 않습니다.

출시 전 실제 수탁자·업무·재위탁 및 국외 처리 여부를 확인합니다. 해당되는 경우 이전받는 자, 국가, 항목, 목적, 시기·방법, 보유기간과 이용자 안내 사항을 구체화합니다.

05. 이용자의 권리와 행사 방법

이용자는 개인정보의 열람·정정·삭제·처리정지 등 관련 요청을 회사의 개인정보 문의 창구로 보낼 수 있도록 할 예정입니다. 회사가 실제 보유하는 정보와 요청 내용을 확인한 뒤 관련 법령에 따라 처리하며, 본인 확인에는 필요한 최소한의 정보만 사용합니다.

기기 내 데이터는 브라우저의 사이트 데이터 관리 기능에서 삭제할 수 있습니다. 앱에 기록 초기화 기능을 추가하는 경우 그 경로를 최종 방침에 안내합니다. 현재 전제에는 앱 계정이 없으며, 추후 계정 생성 기능을 도입하면 계정과 연결 데이터의 삭제 경로도 마련합니다.

06. 안전조치

앱과 웹 콘텐츠의 전송에는 HTTPS를 사용하는 구성을 전제로 합니다. 운영 정보에 대한 접근 권한 최소화, 불필요한 개인정보 수집 방지, 보유기간 관리 및 보안 업데이트를 운영 기준으로 마련합니다. 실제 적용 여부는 배포 전에 확인합니다.

카메라·마이크·연락처·위치 등 민감한 권한을 추가할 경우 필요한 이유와 처리 항목을 먼저 안내하고 관련 권한·동의 절차를 적용합니다.

07. 어린이 이용

교육 앱이라는 이유만으로 특정 연령을 임의로 제외하지 않습니다. 실제 콘텐츠와 이용 대상에 맞춰 타겟 연령 및 어린이 관련 정책의 적용 여부를 결정합니다.

만 14세 미만 아동의 개인정보를 동의에 근거하여 수집하는 기능을 도입하는 경우 법정대리인 동의 등 필요한 절차를 검토·구현하고, 수집 전에 구체적으로 안내합니다.

확정 전: 실제 타겟 연령과 아동 개인정보 처리 여부. 정보 제공형 앱 전제만으로 아동 관련 의무가 모두 면제되는 것은 아닙니다.

09. 방침의 변경 안내

최종 방침을 확정할 때 시행일을 명시합니다. 이후 처리 항목, 기능, 제공·위탁 관계 또는 보유기간이 변경되면 이 페이지에 변경 내용과 적용일을 안내하고, 필요한 경우 앱 내 공지나 추가 동의 절차를 진행합니다.
