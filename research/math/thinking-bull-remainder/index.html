생각하는황소형
배수·나머지 문제

여러 나머지 조건을 최소공배수와 합동식으로 압축하는 자체 연습문항입니다. 공식 입학시험 문항이나 실제 입학시험 난도를 재현한 자료가 아닙니다.

정답 · 119

교육 자료·구현 대조 · 2026-10-20 개정

자체 문제의 최소 해 119 검산 완료. 1부터 1000까지 정수 탐색으로 네 나머지 조건과 7의 배수 조건을 함께 만족하는 첫 수가 119임을 확인했습니다. 일반 해는 N=119+420t(t≥0인 정수)입니다.

생각하는황소 공식 안내 목록의 입학시험 영상 연결을 확인한 범위이며, 영상 내용을 시청·대조하거나 현재 입학시험의 출제·문항 수를 검증한 것은 아닙니다.

월간 통계 기준월은 비적용입니다. 확인일을 9·10월 자료 기준으로 바꾸지 않으며 원문 학년도·시행일·파일 판본을 구분합니다. 출처·계산 검산·후속 조치 JSON 내려받기

문제

자연수 N이 2,3,4,5로 나누었을 때 각각 나머지가 1,2,3,4이고, 동시에 7의 배수이다. 이러한 N 중 가장 작은 수를 구하여라.

공개된 실제 입학시험 원문을 그대로 옮긴 문제가 아니라, 기관의 문항·난도 인증을 받지 않은 교육용 자체 문제입니다.

핵심 풀이

1. 네 개의 나머지 조건을 한 줄로 바꾼다.

N을 2,3,4,5로 나눈 나머지가 각각 ‘나누는 수보다 1 작은 값’이다. 따라서 N+1은 2,3,4,5의 공배수다.

N + 1 ≡ 0 (mod 2,3,4,5)
2. 최소공배수로 압축한다.

lcm(2,3,4,5)=60 이므로 N+1=60k, 즉 N=60k−1.

3. 7의 배수 조건을 적용한다.
60k−1 ≡ 0 (mod 7)
4k ≡ 1 (mod 7)
k ≡ 2 (mod 7)

가장 작은 양의 k는 2이므로 N=120−1=119.

인터랙티브 확인

k를 움직이며 후보 N=60k−1을 확인하세요. 7로 나누어떨어지는 첫 지점이 k=2입니다.

출처·검증

공식 사이트의 입학시험 안내 영상 연결은 확인했습니다. 영상 원문과 현행 지점별 문항 수·운영 방식은 이번에 대조하지 않았으므로 기존 ‘중등 40문항’ 주장을 삭제했습니다.
