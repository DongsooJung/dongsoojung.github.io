AI 모델은 최근 검색 동향을
얼마나 알고 있을까?

2023~2026년 Google·Naver 검색 동향을 사례로, 언어모델의 사전학습 지식과 조회 시점의 최신 데이터를 구분합니다.

실제 검색 동향: ChatGPT와 Gemini

한국의 두 플랫폼에서 동일한 영문 검색어를 조회했습니다. 아래 값은 각 플랫폼이 정규화한 상대 검색 관심도이며 검색 건수가 아닙니다. 2023년 1월~2026년 9월 자료를 2026년 9월 26일에 확인했습니다.

자료를 불러오는 중입니다.

월별 선은 각 월에 시작한 주간 지수의 산술평균입니다. Google과 Naver의 지수 50은 서로 같은 검색량을 뜻하지 않습니다. ‘Gemini’는 다른 의미로도 검색될 수 있어 AI 서비스만의 관심도를 분리하지 못합니다.

대표 사례: GPT-4o (GPT-4 계열)

OpenAI가 공개한 GPT-4o 모델의 지식 기준 시점은 2023년 10월 1일입니다. 따라서 웹 검색이나 별도 데이터 연결 없이 2023년 10월 이후부터 2026년까지의 검색량 변화, 최신 순위, 갑작스러운 이슈를 정확히 답한다고 가정할 수 없습니다. GPT-4o를 2023년 기준 사례로 명시합니다. 원래 GPT-4와 GPT-4 Turbo는 기준 시점이 서로 다릅니다.

지식 기준 시점은 개별 Google·Naver 검색 데이터가 학습에 포함됐는지, 어느 범위까지 포함됐는지를 증명하지 않습니다. 공개되지 않은 학습 데이터의 세부 구성은 단정하지 않습니다.

해석과 다음 검증

2023년 기준 시점 이후의 변화는 GPT-4o의 사전학습 지식만으로 최신 수치를 재현할 수 없다는 문제를 보여주는 사례입니다. 이 시계열만으로 GPT-4o가 실제로 어떤 답을 했는지 또는 특정 자료를 학습하지 않았는지는 판정할 수 없습니다.

다음 실험에서는 동일 질문에 대한 GPT-4o의 도구 미사용 답변과 검색 도구를 사용한 답변을 저장하고, 같은 조회일의 시계열과 방향·순위·근거를 비교해야 합니다. 웹 조회는 답변에 최신 자료를 제공하지만 모델 가중치를 즉시 갱신하지 않습니다.
