1. P와 NP의 엄밀한 뜻

P · POLYNOMIAL TIME

다항시간에 결정할 수 있는 문제

결정문제에 대해 결정론적 계산으로 입력 길이 n의 다항식 시간 O(nk) 이내에 예/아니오를 판정할 수 있는 언어들의 집합입니다. 여기서 k는 해당 알고리즘에 고정된 상수입니다.

NP · VERIFY IN POLYNOMIAL TIME

증명서를 다항시간에 검증할 수 있는 문제

예 답에 대한 다항 길이 증명서(해 후보)를 받아 결정론적으로 다항시간에 확인할 수 있는 결정문제들의 집합입니다. NP는 'not polynomial'의 약자가 아닙니다. 예인 입력에는 적어도 하나의 유효한 증명서가 있고, 아니오인 입력은 어떤 증명서도 검증기를 통과하지 않아야 합니다. [2, 1~2쪽]

P ⊆ NP   /   미해결 질문: P = NP ?

핵심은 최악 사례에 대한 모든 입력에 적용되는 다항시간 알고리즘이 존재하는지입니다. 실제 입력 몇 개를 빠르게 푸는 것만으로는 결론을 낼 수 없습니다. [1]

2. 3-SAT와 NP-완전성

3-SAT는 각 절(clause)에 리터럴이 최대 3개 들어가는 논리식의 만족 가능 여부를 묻는 문제로, 대표적인 NP-완전 문제입니다. Cook의 정확히 3개 리터럴 정의와 여기서 쓰는 최대 3개 정의는 리터럴 반복을 허용하면 같은 만족 가능성 문제로 옮길 수 있습니다. [2, 4~5쪽] NP-완전 문제는 NP에 속하면서 NP의 모든 문제가 다항시간 환원되는 문제입니다.

P⊆NPNP-완전 문제는 NP의 모든 문제를 다항시간 환원으로 포괄

P = NP를 증명하려면

3-SAT처럼 하나의 NP-완전 문제에 대해 모든 입력에 작동하는 다항시간 결정 알고리즘·정확성·최악 시간 상한 증명을 제시하면 충분합니다. 해당 환원으로 모든 NP 문제가 P에 속하게 됩니다.

P ≠ NP를 증명하려면

하나의 NP-완전 결정문제(예: 3-SAT)가 어떠한 결정론적 다항시간 알고리즘으로도 해결되지 않음을 일반적으로 증명하면 충분합니다. 특정 탐색 알고리즘이 느리다는 분석은 부족합니다.

4. STARGATE 연구 과제

  1. 문제·환원 정확성: 3-SAT→그래프 문제 등 다항시간 환원에서 입력 크기와 계산 비용을 명시적으로 증명합니다.
  2. 알고리즘 기준선: 3-SAT에 완전탐색, DPLL, CDCL(SAT 솔버)을 적용해 최악 사례·경험적 성능을 구분합니다.
  3. 증명 장벽 검토: 상대화(relativization), 자연스러운 증명(natural proofs), 대수화(algebrization) 같은 대표적 장벽을 검토합니다. 이들은 해당 성질을 가진 증명 전략의 한계이며 모든 수학적 접근이 불가능하다는 정리가 아닙니다. 자연스러운 증명 장벽의 일반 회로 하한 논의에는 강한 의사난수 생성기 존재와 같은 복잡도 가정이 붙습니다. [2][4]
  4. Lean 형식화: 작은 환원 정리나 솔버의 부분 정합성을 정리증명기에 옮겨 검증합니다. 계산 실험과 전역적 하한 증명은 명확히 구별합니다.
  5. 산업 적용 분석: 조합최적화·일정 계획·회로 검증 및 암호 분야에서 최악 복잡도와 현실적인 근사·휴리스틱 성능을 분리해 평가합니다.

DPLL·CDCL 성능 비교와 Lean 환원 형식화는 아직 연구 계획이며 이 페이지에서 구현·실측하지 않았습니다. P = NP가 증명되더라도 다항식 차수나 상수가 매우 크면 실제로 쓸 만한 알고리즘이 즉시 생긴다는 뜻은 아닙니다.
