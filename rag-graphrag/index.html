질문 지형 측정

실제 질의 로그를 국소·엔티티·다중 홉·전역 유형으로 층화하고 50–200개 골든 평가셋을 만듭니다.

FOUNDATION

표준 RAG 기준선

파싱 품질을 육안 검수하고 청킹 2–3안, 한국어 임베딩, 하이브리드 검색과 리랭커를 비교합니다.

BASELINE

GraphRAG 파일럿

핵심 문서 100–300건에서 도메인 스키마, 엔티티 해소 규칙, 커뮤니티 요약 품질과 비용을 검증합니다.

PILOT

라우팅·운영화

질문별 경로를 자동 선택하고 p95 지연, 질의당 비용, 충실도, 무응답률을 지속 모니터링합니다.
