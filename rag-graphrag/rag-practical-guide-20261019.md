# RAG 실무 가이드 - 출처 대조 개정판

작성: 주식회사 별의문 | 최초 원고: 2026-07-25 | 개정: 2026-10-19

## 문서의 기준과 검증 범위

이 문서는 월간 통계가 아닌 아키텍처 검토 자료입니다. 기준월은 비적용입니다. 이번 개정은 원논문과 Microsoft 공식 문서의 개념 대조이며, 사내 코퍼스 벤치마크나 유료 모델 실행 결과가 아닙니다. 자료 수집시각은 공개 대조 기록의 원출처 응답 수신시각으로 구분합니다.

## 1. 원논문과 현대 실무 설계의 구분

Lewis 등의 RAG 논문 v4(2021-04-12)는 매개변수 모델과 외부 검색 메모리를 결합합니다. 논문의 Wikipedia 밀집 인덱스와 학습 실험을 현대의 모든 RAG 구성으로 일반화하지 않습니다. 아래 파이프라인은 이 문서의 실무 설계안이며 원논문 구현을 재현했다는 뜻은 아닙니다. [R1]

RAG는 조회한 근거를 답변 생성에 제공하는 방식입니다. 문서가 바뀌면 파싱·인덱스·임베딩·캐시의 갱신과 실제 검색 반영을 확인해야 합니다. 재학습이 필요 없다는 사실이 즉시 최신성이나 정답을 보장하지는 않습니다. [R1]

## 2. 비교할 기준선

원문과 권한·버전을 보존하고 파싱한 뒤, 청크 검색과 답변 생성을 분리해 평가합니다. 청크 크기, 중첩, 검색 개수, 재순위화는 도메인별 실험 변수입니다. 특정 토큰 수나 평가 문항 수를 공식 필수 기준으로 제시하지 않습니다.

벡터 검색을 기준선으로 두고 키워드 검색, 하이브리드 결합, 재순위화를 각각 비교할 수 있습니다. 이 선택은 실무 가설이며 어떤 구성이 항상 더 정확하거나 저렴하다는 실측 결론은 없습니다. Microsoft GraphRAG의 Basic은 상위 k개 텍스트 유닛을 이용하는 비교용 벡터 검색 구현입니다. 이 페이지의 표준 RAG 설계안과 Basic을 동일한 구현으로 취급하지 않습니다. [R2]

## 3. 질의 유형별 검토

- 단일 사실: 정답 근거 청크가 검색됐는지, 실제 답변이 그 근거를 지지하는지 확인합니다.
- 엔티티 상세: GraphRAG Local의 그래프 자료와 원문 결합을 비교 후보로 둡니다. [R3]
- 다중 홉: 한 번의 top-k가 관계를 놓칠 수 있습니다. 질의 분해·반복 검색·그래프 경로를 같은 평가셋에서 비교합니다. 모든 RAG가 원리적으로 처리 불가능한 문제로 일반화하지 않습니다.
- 전역 질문: Edge 등의 논문은 특정 전역 요약 평가에서 GraphRAG를 기존 RAG 기준선과 비교했습니다. 이 결과는 모든 코퍼스·한국어·업무에서의 우위를 보장하지 않습니다. [R4]

## 4. 파일럿 평가 설계안

질의와 정답 근거를 유형별로 표본화합니다. 검색 재현율·순위, 근거 지지도·답변 정확도, 무응답의 적절성을 구분합니다. 지연시간과 입력·출력 토큰, 인덱싱·갱신 소요량도 별도로 수집합니다. 이 항목들은 앞으로 실행할 평가 설계이며 현재 측정값은 없습니다.

권한은 검색 결과와 생성 문맥 모두에서 확인하고, 원문 버전 및 실제 인용 위치를 보존합니다. 생성된 답변·요약이 원문과 일치하는지 사람의 표본 검토를 포함합니다. 표본 수와 합격 기준은 업무의 오류 비용과 평가 변동성을 보고 정합니다.

## 5. 이번에 정정한 주장과 남은 작업

7월 원고의 즉시 갱신, 특정 구성의 보편적 우위, RAG의 전역·다중 홉 불가능 단정을 완화했습니다. 화면의 근거 없는 0-100 점수와 실측으로 제시됐던 라우팅 비율은 삭제했습니다. 어떤 방식이 더 빠르고 저렴한지는 아직 측정하지 않았습니다.

다음 작업은 실제 코퍼스·권한·변경 시나리오와 정답 근거를 확보하고, 고정 버전·설정으로 기준선과 후보를 비교하는 것입니다. 모델 호출과 과금은 이번 출처 점검에서 실행하지 않았습니다. 7월 파일은 수정하지 않은 보관본이며 현재 가이드는 이 개정판입니다.
