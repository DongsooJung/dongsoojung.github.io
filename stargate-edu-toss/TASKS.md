# 토스 미니앱 전환 작업표

## 이 패키지에 반영된 것

- [x] 포털 TWA 전체를 감싸지 않고, KOI 학습 경로와 교육용 연습만 번들로 분리
- [x] 라이트 모드만 사용하고 핀치 줌을 끔
- [x] 자사 홈, Play 설치, 상담 메일, 연구 대시보드 링크를 넣지 않음
- [x] 앱인토스 Storage 어댑터. 글 입력은 400ms, 체크와 채점은 즉시 1회 저장
- [x] 문제 시트가 열려 있을 때만 뒤로가기를 가로채 시트를 닫음. 첫 화면의 뒤로가기는 토스 기본 동작으로 미니앱을 종료
- [x] 풀이만 보기는 맞힌 기록에 넣지 않음
- [x] `npm test`로 예시 계산과 출시 금지 패턴을 확인

## 0단계. 콘솔 등록

1. https://apps-in-toss.toss.im/ 에서 워크스페이스 주식회사 별의문을 확인합니다.
2. 미니앱 이름 별의문 스타게이트, 영문명 Stargate Edu, appName `stargate-edu`, 비게임, 교육으로 등록합니다.
3. 워크스페이스 키로 `ait token add`를 실행합니다. 키는 저장소에 넣지 않습니다.
4. `npm run build` 다음 `npx ait deploy`로 번들을 올립니다.
5. 토스 앱 QR 테스트 뒤에만 검수를 요청합니다.

## 다음 구현

2. `User.getAnonymousKey()`로 기기 변경 뒤에도 기록을 남기는 서버 동기화. 변경은 `src/storage.js`만 합니다.
3. 힌트를 모두 쓴 뒤에만 보상형 광고로 풀이를 여는 선택 기능.
4. 비게임 출시 체크리스트와 코드를 한 줄씩 대조합니다.
