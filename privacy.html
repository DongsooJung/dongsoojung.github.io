개인정보처리방침

적용 대상: Stargate Android 앱 및 stargateedu.co.kr 웹사이트
운영자: Stargate Corporation (대표 정동수) · 시행일: 2026-10-15

Stargate Android 앱은 웹사이트 stargateedu.co.kr을 그대로 표시하는 앱이며, 앱 자체에서 추가로 수집하는 정보는 없습니다. 아래 내용은 앱과 웹사이트 이용 시 처리되는 정보를 모두 설명합니다. 회원가입 기능은 없습니다.

1. 처리하는 정보와 목적

  • 상담 신청 (상담 페이지에서 직접 신청하는 경우에만)
    항목: 이름, 휴대전화번호, 카카오·네이버 간편 입력을 사용한 경우 해당 서비스의 회원 식별값
    목적: 상담 접수 및 연락 · 보관: 상담 종료 후 1년
  • 방문 통계 (자동 처리)
    항목: 브라우저에 저장되는 무작위 방문자·세션 식별값, 방문 페이지 경로와 제목, 클릭한 메뉴·링크, 기기 유형(모바일/PC), 방문 일자
    목적: 방문자 수 집계와 서비스 개선 · 이름, 연락처 등 개인을 직접 식별하는 정보는 포함하지 않습니다 · 보관: 수집일로부터 3년
  • 날씨 기능의 위치 (해당 기능에서 위치 사용을 허용한 경우에만)
    대략적인 위치(위도·경도)를 날씨 조회에만 사용하며 운영자의 서버에 저장하지 않습니다.

2. 처리 위탁 및 외부 서비스

  • Supabase: 상담 신청 데이터 저장
  • Firebase: 방문 통계와 페이지·버튼 사용 분석 저장
  • GitHub Pages, Vercel: 웹사이트 호스팅 및 API 운영 (서비스 제공과 보안을 위해 IP 주소 등 접속 기록을 처리할 수 있음)
  • 카카오, 네이버: 이용자가 간편 입력을 선택한 경우 본인 확인
  • Open-Meteo: 날씨 기능 사용 시 위치 기반 날씨 조회

위 목적 외에 개인정보를 제3자에게 제공하거나 판매하지 않으며, 광고를 표시하지 않습니다. 모든 전송은 암호화된 연결(HTTPS)로 이루어집니다.

3. 파기

보관 기간이 끝나거나 처리 목적이 달성된 정보는 지체 없이 삭제합니다.

4. 이용자의 권리와 삭제 요청

이용자는 언제든 본인 정보의 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다. 아래 이메일로 요청하시면 확인 후 지체 없이 처리합니다. 방문 통계 식별값은 브라우저(또는 앱)의 사이트 데이터를 삭제하면 기기에서도 지워집니다.

5. 아동의 개인정보

본 서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 만 14세 미만 아동의 상담 신청은 법정대리인을 통해 진행합니다.
