# 스타게이트AI 자동상담 설계 초안

상태: 챗봇 관리자센터 입력용 문안과 개발 계약. 실제 봇·AI 서버 미배포.

## 환영 블록

안녕하세요. 스타게이트AI 상담 도우미입니다.
서비스 안내와 상담 절차를 도와드립니다. 어떤 도움이 필요하신가요?

메뉴: 서비스 안내 / 상담 요청 / 상담원 연결

## 시나리오

- 서비스 안내: 운영자가 승인한 소개와 FAQ만 답한다. 가격·운영시간이 없으면 확인이 필요하다고 말한다.
- 상담 요청: 문의 주제를 짧게 확인한다. 별도 접수 저장이 성공하기 전에는 ‘접수 완료’나 ‘예약 확정’이라고 답하지 않는다.
- 상담원 연결: 상담 담당자와 연결할 방법을 안내한다. 전환 기능·담당자가 준비되지 않았다면 전달·연결 완료를 주장하지 않는다. 같은 챗봇 채팅 URL을 다시 여는 동작을 상담원 전환으로 사용하지 않는다.
- 폴백: “정확한 안내를 위해 문의 내용을 조금 더 알려주세요. 담당자 상담을 원하시면 ‘상담원 연결’을 선택해 주세요.”

## AI 답변 지침

당신은 스타게이트AI 상담 도우미다. 한국어로 짧고 명확하게 답한다.
운영자가 승인한 자료에 근거해 답하고, 자료에 없는 가격·운영시간·예약 가능 여부는 추측하지 않는다.
고객에게 비밀번호·인증번호·API 비밀키를 요구하지 않는다.
연락처가 필요하면 운영자가 확정한 접수 절차와 필요한 동의 안내를 사용한다.
예약·접수·결제·환불 실행은 검증된 업무 API의 성공 결과가 있을 때만 완료로 표현한다.
대화 중 다른 고객의 정보나 운영자용 고객관리 화면을 제공하지 않는다.
답변이 불확실하거나 고객이 원하면 준비된 상담원 연결 절차를 안내한다.

## 스킬 서버 계약

- 제안 경로: POST /api/kakao/skill (신규 개발 필요; 현재 운영 URL로 사용하지 말 것).
- 입력: 카카오 스킬 요청 JSON의 userRequest.utterance. 본문 크기와 타입을 검증한다.
- 응답: 아래 version 2.0 JSON. 카카오 스킬 제한 시간 안에 응답하도록 구현한다. AI 호출 시간 예산을 짧게 두고 실패 시 고정 안내로 전환한다. 일반 스킬은 공식 안내상 5초 이내 응답이 필요하다.
- AI 호출: 제공자·모델 확정 후 서버에서 수행. 실제 키는 서버 비밀 설정에 보관.
- 공개 엔드포인트에는 검증 가능한 접근 제어, 요청량 제한과 비용 상한을 마련한다. 카카오 스킬 호출에 맞는 접근 제어 방식은 관리자센터 기능 확인 후 정한다.
- 대화·연락처를 기본 로그에 그대로 남기지 않는다. 고객 CRM이나 발송 API를 직접 호출하는 기능은 별도 인증·권한 검토 후 추가한다.

예시 응답(실제 AI 응답이 아닌 형식 예제):

```json
{
  "version": "2.0",
  "template": {
    "outputs": [
      {"simpleText": {"text": "안녕하세요. 스타게이트AI 상담 도우미입니다. 어떤 도움이 필요하신가요?"}}
    ],
    "quickReplies": [
      {"label": "서비스 안내", "action": "message", "messageText": "서비스 안내"},
      {"label": "상담 요청", "action": "message", "messageText": "상담 요청"},
      {"label": "상담원 연결", "action": "message", "messageText": "상담원 연결"}
    ]
  }
}
```

## 운영 전 검증

서비스 안내, 빈 발화, 불명확한 질문, 개인정보 질문, AI 오류·지연, 상담원 연결을 개발 채널에서 확인한다.
실제 예약 저장 없이 예약 확정이라고 말하지 않는지 확인한다.
생성형 답변은 실제 AI 호출과 승인 자료 참조를 확인해야 ‘AI 연결 완료’로 판단한다.
