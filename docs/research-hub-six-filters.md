# 연구 허브 7개 필터 적용

2026-10-16 기준. 포털의 `research/index.html`과 공유 스크립트 `assets/intelligence-hub.js`에 적용합니다.

필터는 전체를 포함해 7개입니다. 사용자 요청으로 기존 연구 난제 7개 전체를 연구·AI에서 난제·에세이로 분리했습니다. 각 카드는 `data-primary`로 대표 분류 하나를 갖고, 기존 `data-category`는 보조 태그로 남깁니다. 관측·연구·난제·교육·운영의 다섯 레인은 그룹의 `data-lane`으로 구분합니다.

| 필터 | 고유 카드 | 그룹 |
|---|---:|---|
| 전체 | 63 | 전체 9개 그룹 |
| 도시·공간 | 21 | 실시간 도시 5, 행정경계 9, 접근·부동산 7 |
| 경제·사회 | 13 | 거시·산업 11, 커뮤니티 신호 2 |
| 연구·AI | 9 | 연구 방법·AI 9 |
| 난제·에세이 | 7 | 모순연구소, 기후, 한국, 통일, 양자물리, 심해·지구 내부, 질병 |
| 교육·수학 | 7 | 교육·수학 7 |
| 운영·제품 | 6 | 운영·제품 6 |

기존 61개 개편안에 월간 날씨 캘린더와 OneNote·Notion 상태판을 포함해 고유 프로젝트는 63개입니다. 서울 실시간 도시데이터와 접근성 랩의 중복 두 장을 제거했습니다. 네 수학 아카이브를 HTML에 포함해 스크립트 주입 여부에 따른 집계 차이도 없앴습니다.

API는 수집 방식으로 유지합니다. 공항 혼잡은 도시·공간, 관광·숙박 수요와 Airbnb 수익 분석은 경제·사회, 공공데이터 수집 기록소는 연구·AI에 둡니다. 모순연구소와 기후·한국·통일·양자물리·심해·질병 난제는 난제·에세이, 수학 학습 AI는 교육·수학으로 분류합니다. 기존 `#grand-challenges` 주소는 유지합니다.

그룹 순서는 고정하고 사용빈도·가나다 정렬은 그룹 안에서만 적용합니다. 초기에는 레인별 첫 그룹을 펼치고, 필터·검색 시 일치하는 그룹을 펼칩니다. 조건을 해제하면 이전 펼침 상태를 복원합니다. 기존 그룹 앵커는 별칭으로 보존하며, 접히거나 필터로 숨겨진 그룹에 접근하면 해당 그룹을 엽니다.

후속 적용: 연구 허브의 기본 정렬은 가나다순이며, 각 필터의 결과 전체를 한 목록으로 정렬합니다. 사용빈도순과 앵커 이동에서는 기존 그룹을 유지합니다. 출처·자료 기준 최신화는 [하루 간격 실행 계획](research-refresh-plan.md)을 따릅니다.

히어로와 필터별 숫자는 실제 카드에서 계산합니다. 홈의 고유 프로젝트 문구와 HTML 기본 숫자는 카드 추가 시 함께 갱신하고 `tests/research-hub.test.cjs`로 일치를 검사합니다.

분리 후 검증: 연구·AI 9개, 난제·에세이 7개, 전체 63개의 상호 배타적 분류와 출처 원장·일일 점검 분류 일치를 검사합니다. 브라우저에서 각 필터의 가나다순, 난제 7개 전부의 포함·제외, ‘기후’·‘환율’ 검색, 빈 결과, 펼침 상태 복원, 그룹 순서, 그룹 안 사용빈도 정렬, 기존 앵커, 키보드 조작, 모바일 가로 넘침, 전략 허브의 기존 필터를 확인했습니다.
