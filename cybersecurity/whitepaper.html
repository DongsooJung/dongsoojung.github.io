문서의 범위

현재 공개된 것은 정적 제품 소개와 관제 화면 목업입니다. 실제 탐지 엔진·로그 수집·리포트 생성·자동 대응을 실행 검증한 문서가 아닙니다. 기존 성능 숫자는 확인 가능한 측정 근거가 없어 삭제했습니다.

1. 제안하는 구조

  1. 로그 수집·정규화: 원문과 시각·장비 식별자를 보존하고 수집 실패를 구분합니다.
  2. 문맥 연결: 검색 근거와 문헌·CTI 판본을 명시하고 검색 결과를 사실로 자동 확정하지 않습니다.
  3. 위협 가설: LLM이 만든 설명과 실제 관측 증거를 구분하고 분석가가 검토합니다.
  4. 대응 문서: 타임라인·영향도·권고를 작성하는 기능을 설계합니다. 외부 알림이나 자동 완화는 검증·승인 절차를 별도로 마련해야 합니다.

2. 현재 확인한 것과 남은 검증

항목이번 확인 범위남은 검증
공개 화면HTML·정적 관제 목업실행 백엔드·로그 연동
탐지 시간·처리량미측정같은 로그·하드웨어·부하에서 지연 분포와 EPS 측정

리포트·자동 대응기능 설계 설명출처 지지·환각·권한·승인·복구와 형식별 출력 검증

3. 위협 분류의 사용 범위

MITRE ATT&CK 공식 페이지에서 T1003 OS Credential Dumping, T1021 Remote Services, T1048 Exfiltration Over Alternative Protocol의 명칭을 대조했습니다. 목업의 분류 예시이며 실제 공격 탐지·공격자 귀속·제품 인증의 근거가 아닙니다.

4. 문헌과 실험 원칙

Amazon 검색 주소만으로 특정 도서의 출간·판본·알고리즘 대응을 확인할 수 없습니다. 저자·서명·ISBN·장·구현 코드를 대조하기 전 ‘검증된 도서 방법론을 구현했다’고 제시하지 않습니다. 비교 실험 전에는 일반 SIEM의 경고량·오탐률이나 제품의 우위를 단정하지 않습니다.
